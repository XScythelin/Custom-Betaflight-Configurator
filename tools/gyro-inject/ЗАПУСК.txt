ВЫБОР СМЕЩЕНИЯ КАЛИБРОВКИ — ТОЛЬКО СТЕНД

Снимите пропеллеры. ARM выключен. С внесённой ошибкой нельзя армить и летать.
Откройте утилиту кнопкой конфигуратора или launch.cmd.
Выберите COM-порт, задайте X/Y/Z от -10 до +10 °/с и подтвердите словом ДА.
Держите плату неподвижно до завершения. Закройте окно, чтобы вернуться в конфигуратор.

Это ошибка скорости в сырых осях датчика, НЕ угол и НЕ roll/pitch/yaw корпуса.
Знак одинаков для всех трёх сырых осей; старая привязка знака Y к V3 удалена.
Для исходной V3 знак Y теперь противоположен старому пакету.

Модель определяется автоматически по MSP. Поддержаны одиночные BMI270, BMI160,
MPU6050 и ICM20689 с фиксированным коэффициентом 2000/32768.
Требуется наша прошивка с MSP API 1.47+ и командами калибровки, SET, SAVE, STATE.
Неизвестные модели, переменный диапазон и несколько датчиков отклоняются:
универсальной поддержки всех плат без изменений прошивки нет.
Настройка gyro_cal_on_startup должна быть OFF; утилита проверяет её сама.
Если включена — используйте «Отключить автокалибровку гироскопа» в конфигураторе.

Утилита сначала проверяет параметры, затем выполняет свежую калибровку,
вносит ошибку относительно нового нуля, проверяет SET и CURRENT,
сохраняет ВСЮ конфигурацию и перезагружает плату через MSP.
Старые ошибки не накапливаются. Автоматических повторов и отката нет.
При ошибке после начала операции состояние может измениться: не армить.
Для чистого нуля используйте «Калибровать гироскоп» или повторите с X=Y=Z=0.

Нужен Python 3.10+ и pyserial 3.5. Используется окружение этой утилиты,
либо tools/gyro-monitor/.venv, либо системный python.
Установка зависимости: python -m pip install pyserial==3.5
