# Консольный монитор гироскопа

Из корня репозитория в Windows Terminal / PowerShell:

```powershell
python -m pip install pyserial
python build/gyro_live.py --port COM3
```

Закрыть Configurator и другие программы, занимающие COM-порт. На FC должен
быть заранее включён IMU stream `0x3010` на выбранном порту; монитор ничего
сам не настраивает поток. По клавише `C` отправляется START калибровки
`0x3013`; монитор ждёт автоматический RESULT `0x3015` и показывает
SUCCESS/FAILED, время ожидания и raw offsets (не °/с).
Запрос меняет только RAM-смещения, EEPROM не сохраняется. Для этой
стендовой проверки плата должна быть неподвижна, disarmed, без пропеллеров.
Повторный запрос до ответа блокируется; при отсутствии ответа более 35 с
итог считается неизвестным, автоматических повторов нет. Поздний ответ
будет принят. Протокол не содержит ID операции, не запускайте калибровку
параллельно из другого клиента. Из STATE `0x3011` выводится attitude
Roll/Pitch/Yaw в градусах рядом с соответствующей осью гироскопа, фиолетовым
цветом. Углы обновляются потоком около 20 Гц, без интерполяции. В заголовке
раздельно показаны измеренные частоты IMU и STATE за последние 2 секунды.
MAG пакеты пропускаются. Если STATE отсутствует или устарел, виден статус.

- XYZ: угловая скорость в °/с из firmware, без дополнительного сглаживания
  и без вычитания среднего. Это не сырые ADC и не угол ориентации.
- Экран обновляется по приходу IMU/STATE, без лимита FPS. Если USB доставил
  несколько пакетов за раз, читаются все, а экран показывает последний.
  При отсутствии данных служебные предупреждения обновляются раз в 0,1 с.
- Среднее, стандартное отклонение и максимум модуля по всем валидным samples
  за последние 5 секунд; std показывает разброс вокруг среднего.
- Над каждым графиком: MIN и MAX только видимых точек, со знаком,
  а не за окно статистики и не границы Y. При достаточном месте название
  оси, угол ATTITUDE и экстремумы выводятся крупными масштабируемыми глифами.
  При уменьшении окна используется компактная строка. Крупные экстремумы
  округлены до 0,001 °/с, угол — до 0,1°. AUTO Y рассчитывается по тем же
  видимым точкам, но оставляет запас и плавно сужается после пиков.
- Графики показывают последние IMU samples; статистика учитывает все
  валидные samples за 5 секунд. AUTO Y включён по умолчанию, диапазон
  каждой оси независим: 10% запаса над пиком видимой истории, расширение
  сразу, сужение быстрое и плавное после 0,5 с низкой активности.
  Ноль по центру. Для старта без AUTO: `--no-auto-scale`.
- `A` переключает AUTO/ручной Y. `+` уменьшает минимальный диапазон AUTO
  (либо ручной диапазон) вдвое, `-` увеличивает; `R` сбрасывает
  статистику/графики, не калибровку FC. `Q` или `Ctrl+C` — выход.
  Клавиши `+/-/R/Q` доступны в Windows; `Ctrl+C` работает также на Linux.
- Размеры графиков автоматически подстраиваются под ширину и высоту окна,
  включая изменение размера во время работы. Все три графика имеют равную
  высоту, ноль остаётся по центру. Минимум: 30 колонок × 23 строки;
  для читаемых подписей рекомендуется ширина от 85 колонок.
  Размер шрифта меняется средствами терминала прямо во время работы:
  в Windows Terminal — `Ctrl` + колёсико мыши. Скрипт сам шрифт не меняет,
  но адаптирует графики к изменившемуся количеству строк/колонок.
  Используется основной экранный буфер, без alternate-screen. Если терминал
  не поддерживает этот жест, использовать его меню размера шрифта.
- При отсутствии свежих данных дольше 0,5 с появляется предупреждение.
  Неконечные значения не отображаются и увеличивают счётчик invalid.

Для особенно мелких колебаний:

```powershell
python build/gyro_live.py --port COM3 --scale 0.05
```

Минимальный диапазон AUTO в этом примере ±0,05 °/с. Для фиксированного
диапазона нажать `A`. Ручное обрезание графика не влияет на числа или
статистику. Фактический FPS зависит от терминала.
